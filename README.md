# Hola, soy LopezDev7

Hago frontend pero me gusta meterme también en el backend. Interfaces limpias, APIs, bases de datos, lógica de servidor, de todo un poco.

Ahora mismo estoy en tres cosas: [**public-apis-es**](https://github.com/LopezDev7/public-apis-es), un catálogo de APIs públicas en español que cualquiera puede ampliar con un PR, [**QuickInsight**](https://github.com/LopezDev7/QuickInsight), un resumidor de vídeos y artículos desde la terminal, y [**SampLive**](https://github.com/LopezDev7/SampLive), una herramienta de hot reload para servidores SA-MP y open.mp.

También ando colaborando con [**open.mp**](https://github.com/openmultiplayer/launcher), el launcher open source de SA-MP.

Aparte hago scripting en Pawn para servidores SA-MP, de ahí salió [SampLive](https://github.com/LopezDev7/SampLive).

## Stack

HTML, CSS, JavaScript, TypeScript, Go, Node.js, Express, Python, Java, PHP, C#, C++, MySQL, PostgreSQL, MongoDB, Docker, Git, Linux.

## Proyectos

|----------|-------------|-------|
| [SampLive](https://github.com/LopezDev7/SampLive) | Hot reload para servidores Pawn (SA-MP y open.mp). Guardás el `.pwn`, compila y lo carga sin reiniciar, sin desconectar a nadie. | Go |
